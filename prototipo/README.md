# Prototipo visual (demostración)

`visitas-demo.html` es el prototipo navegable de Fitnessland: visitas individuales y grupales,
vista previa por rol y configuración de sucursales.

- Es una **referencia visual**. Se guarda sin cambios.
- Todo ocurre en el navegador con **datos ficticios**; se reinicia al recargar.
- Sus permisos, validaciones y protección contra duplicados están **simulados**. No son seguridad real.
- **Nunca** se conecta a la base de datos ni a la aplicación.

La aplicación reutiliza de aquí el diseño (colores por sucursal con contraste calculado, tipografía,
tarjetas, barra de contexto y portadas por perfil). La lógica se escribe de nuevo en el servidor.

Para verlo, ábrelo directamente en un navegador.
